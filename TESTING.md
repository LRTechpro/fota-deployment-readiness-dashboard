# User and Logic Testing

## Automated decision tests

Run:

```powershell
npm test
```

The test suite checks a fully ready vehicle, exact boundary values, low voltage, degraded connectivity, and multiple simultaneous blockers.

## User test checklist

Ask at least one tester to complete these tasks without coaching:

1. Load the ready scenario and identify the deployment decision.
2. Change battery charge below 70% and run the evaluation again.
3. Explain why the update was blocked.
4. Restore a passing condition and download the report.
5. View the dashboard at desktop and mobile widths.

Record the tester's name or initials, date, observations, and any change made afterward. Do not invent feedback—replace the blanks below after a real test.
